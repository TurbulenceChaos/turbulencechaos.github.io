\section{Introduction}
\begin{definition}[OpenFOAM]
    OpenFOAM is software for computational fluid dynamics (CFD) \cite{GREENSHIELDS_2026_OPENFOAM_V14_USER_GUIDE}.

    Two categories:
    \begin{itemize}
        \item solvers: perform calculation in fluid
        \item utilities: config simulation, geometry, mesh, and process results
    \end{itemize}
\end{definition}

Install: \url{https://openfoam.org/download/source/}
